Контекст

Пользователи регулярно обмениваются файлами через мессенджер, при этом в продукте отсутствовала антивирусная проверка. Любой заражённый файл мог быть загружен в систему и распространён среди участников рабочих чатов. Для крупных корпоративных клиентов это являлось серьёзным риском иб и ограничивало возможности внедрения продукта.

Файл мог попасть в систему несколькими способами:

  • ✦ через чат;
  • ✦ через аудио- и видеосообщения;
  • ✦ через редактор документов;
  • ✦ через видеоконференции;
  • ✦ через настройки профиля;
  • ✦ через административную панель.

Что я сделала

Важно было создать единую логику поведения независимо от точки входа.

User flow

Решение

В продукт была интегрирована проверка файлов через Kaspersky Security Engine. Любой загруженный файл автоматически проходит проверку перед тем, как станет доступен другим пользователям. В случае угрозы система блокирует дальнейшие действия и сообщает пользователю причину ограничения.

Результат

  • ✦ Отсутствие антивирусной проверки было барьером для внедрения в компаниях с высокими требованиями к информационной безопасности — этот барьер сняли.
  • ✦ Обязательная проверка встроилась в сценарий работы с файлами, не сломав его: единая модель поведения для Desktop и Mobile, блокировка, карантин и уведомления.
  • ✦ Спроектирована интеграция с Kaspersky Security Engine, проработаны все основные точки загрузки файлов в системе.
